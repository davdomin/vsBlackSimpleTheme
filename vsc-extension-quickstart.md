# VS Code Extension Quickstart

## Development

1. Open this folder in VS Code.
2. Press `F5` to open a new window with your extension loaded.
3. Open a source code file to see your theme in action.
4. Modify `themes/vsBlackSimpleTheme-color-theme.json` to see changes update in real-time.

## Commands

* `npm install -g @vscode/vsce`: Install the VS Code Extension Manager.
* `vsce package`: Create a `.vsix` file for manual installation or testing.
* `vsce publish`: Upload the theme to the Marketplace.
