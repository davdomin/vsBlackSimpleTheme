# vsBlackSimpleTheme

A sleek, minimalist dark theme for Visual Studio Code, designed to reduce eye strain and keep you focused on your code.

## Features

* **True Black Background:** Perfect for OLED screens and high-contrast lovers.
* **Simple Syntax Highlighting:** Clear colors without the "fruit salad" effect.
* **Minimalist UI:** Clean sidebars and status bars for a distraction-free environment.

## Installation

1. Open **Visual Studio Code**.
2. Go to **Extensions** (`Ctrl+Shift+X`).
3. Search for `vsBlackSimpleTheme`.
4. Click **Install**.
5. Go to **File > Preferences > Color Theme** and select **vsBlackSimpleTheme**.
